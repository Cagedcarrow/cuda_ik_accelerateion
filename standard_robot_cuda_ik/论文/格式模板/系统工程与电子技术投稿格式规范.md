# 《系统工程与电子技术》投稿格式规范

> 来源：`20210316135031_500.docx` 优先出版模板
> 适用于 LaTeX 写作时快速查阅，重点关注与默认模板不同的规范要求。

---

## 一、整体结构

```
中文文题 → 作者 → 单位 → 摘要 → 关键词 → 中图分类号 → 文献标志码
  ↓
英文 Title → Author → Affiliation → Abstract → Keywords
  ↓
0 引言 → 1 一级标题 → …… → 2 结论 → 参考文献 → 作者简介
```

---

## 二、标题与作者

| 项目 | 规范 |
|------|------|
| 中文文题 | 不超过 20 个汉字，二号宋体加粗 |
| 英文文题 | 不超过 10 个实词，四号 Times New Roman 加粗 |
| 作者姓名 | 四号楷体，置于文题下方 |
| 作者单位 | 小四号，具体到院系/实验室/研究所；多个单位用上角标 1,2 标注 |

---

## 三、摘要与关键词

### 中文摘要（200~250 字）
- 第三人称，不以"本人/作者/我们"作主语
- 写清**目的、方法、结果、结论**
- 不使用图、表、数学公式
- 缩略语首次出现须给出全称
- 避免常识性内容

### 英文摘要
- 是中文摘要的直译
- 时态：一般现在时 / 一般过去时为主
- 避免全角标点符号
- 缩略语首次出现格式：`multiple input multiple output (MIMO)`

### 关键词
- 3~5 个，从大到小排列
- 用全称，缩写须附全称后用括号括起

### 中图分类号与文献标志码
- 中图分类号从《中国图书馆分类法》查得
- 文献标志码统一为 **A**
- 两者在同一行，分类号在左，标志码在右

## 四、正文格式

### 4.1 标题编号

引言编号为 **0**，之后按顺序：1, 2, 3……

| 级别 | 格式 | 示例 |
|------|------|------|
| 一级标题 | 四号宋体加粗 | **1 一级标题** |
| 二级标题 | 五号黑体 | **1.1 二级标题** |
| 三级标题 | 五号楷体 | **1.1.1 三级标题** |
| 四级标题 | 正文格式 | （1）四级标题 |

### 4.2 数学量与符号（GB3102-93）

| 类型 | 字体 | 示例 |
|------|------|------|
| 变量 | 白斜体 | $x, y, \alpha$ |
| 矢量/向量 | **黑斜体** | $\bm{r} = (x, y, z)$ |
| 矩阵 | **黑斜体** | $\bm{A} = [a_{ij}]$ |
| 常量 | 正体 | $\pi, \mathrm{e}, \Delta$ |
| 单位 | 正体 | $\mathrm{dB}, \mathrm{km}, \mathrm{mm}$ |
| 集合 | 黑正体 | $\mathbb{R}, \mathbb{C}, \mathbb{N}, \mathbb{Z}$ |
| 数学运算/函数 | 正体 | $\sin, \log, \mathrm{rank}(\bm{A}), \mathrm{d}$ |
| 转置/共轭符号 | 正体 | $\bm{A}^\top, \bm{A}^\mathrm{H}$ |

### 4.3 数值与单位

- 数值与单位间留一空格：`10 mm`（非 `10mm`）
- 数字三位分节：`2 324.435 67`
- 量符号首次出现时须定义，全文统一

### 4.4 缩写词

- 首次出现格式：`合成孔径雷达（synthetic aperture radar，SAR）`
- 之后只用缩写

## 五、图（Figures）

| 要求 | 说明 |
|------|------|
| 编号 | 全文统一顺序编号（不以章节编号），如 图 1, 图 2 |
| 位置 | **图随文后**——正文先引用，再出现图；图必须放在本节内，**不得跨节** |
| 图题 | 图下方居中，**中文**，小五号（9pt） |
| 分图 | 分图下方标 (a) xxx / (b) xxx |
| 图内文字 | **必须为中文**，字号 6 号（约 7.5pt），不得出现英文 |
| 坐标轴 | 须有量和单位，如 `时间/s`、`位置误差/mm` |
| 变量字体 | 斜体/黑斜/正体与正文一致 |
| 引用方式 | 用"如图 1 所示"，不可用"如下图" |
| 大小 | 半栏宽或通栏，清晰度要高 |

---

## 六、表（Tables）

| 要求 | 说明 |
|------|------|
| 编号 | 全文统一顺序编号（不以章节编号），如 表 1, 表 2 |
| 格式 | **三线表**（顶线、栏目线、底线），复杂表可加辅助线 |
| 位置 | **表随文后**，不能跨节 |
| 表题 | 表上方居中，**中文**，小五号（9pt） |
| 表头 | 必须有表头，放在第一行 |
| 表内文字 | **必须为中文**（必要缩略语除外） |
| 单位 | 全表一致时置于表格右上角（如 `ms`）；按行/列不一致时归并于量名称后（如 `吞吐量/(targets·s⁻¹)`） |
| 数据 | 多位数字每 3 位空 1/4 格 |
| 表注 | 表下方，字号可略小于正文 |
| 引用方式 | 用"如表 1 所示"，不可用"如下表" |

---

## 七、公式（Equations）

| 要求 | 说明 |
|------|------|
| 排版 | 居中排，用公式编辑器录入 |
| 编号 | 全文顺序排号：(1), (2), (3)... |
| 换行 | 前一行的行末必须是运算符（如 +, -, ×, =） |
| 变量 | 全文一个字母只指代一个变量，意义前后一致 |
| 禁止 | 避免用英文单词缩略语代表变量（如 SNR） |
| 向量/矩阵 | 黑斜体；其他变量白斜体；常量正体 |

---

## 八、参考文献

### 基本要求
- **按正文引用顺序排列**，不以字母排序
- **15 条以上**，英文文献占 **2/3 以上**
- 主要引用近 3 年期刊文献
- 中文文献需提供英文著录格式
- 正文引用：不作句子成分用上角标 `［1］`，作句子成分平排

### 文献类型标志

| 代码 | 类型 | 代码 | 类型 |
|------|------|------|------|
| J | 期刊 | M | 普通图书 |
| C | 会议录 | D | 学位论文 |
| P | 专利 | R | 报告 |
| S | 标准 | EB | 电子公告 |
| G | 汇编 | N | 报纸 |

### 著录格式示例

**期刊** `[J]`：
> 析出文献主要责任者. 析出文献题名[J]. 连续出版物题名, 年, 卷(期): 起页-止页.
>
> 刘天坤, 熊新平, 赵育善. 网络化防空导弹体系生存能力的评估与权衡[J]. 系统工程与电子技术, 2007, 29(2): 226-229.
>
> LIU T K, XIONG X P, ZHAO Y S. Research on survivability evaluation and tradeoff of networking air defense missile systems[J]. Systems Engineering and Electronics, 2007, 29(2): 226-229.

**会议** `[C]`（按专著析出文献格式）：
> 析出文献主要责任者. 析出文献题名[C]// 会议录主要责任者. 会议录题名. 出版地: 出版者, 出版年: 起页-止页.
>
> CHONG C Y, KUMAR S P. Sensor networks: evolution, opportunities and challenges[C]//Proc. of the Sensor Networks and Applications. Washington: IEEE Press, 2003: 1247-1256.

**图书** `[M]`：
> 主要责任者. 题名[M]. 版本项. 出版地: 出版者, 出版年: 起页-止页.

**学位论文** `[D]`：
> 主要责任者. 题名[D]. 保存地: 保存单位, 年份: 起页-止页.

**电子文献** `[EB/OL]`：
> 主要责任者. 文题[EB/OL]. [引用日期]. 获取和访问路径.

### 注意事项

- 作者：姓前名后，名用缩写（首字母），缩写后不加点。超过 3 人加 "，等" 或 ", et al"
- 期刊名：**全称**，不缩写（IEEE 等可用公认简写，Trans. on 缩写为 Trans. on）
- 会议名：全称，不缩写简写，但 `Proceeding of` → `Proc. of`
- 文献题名：首词首字母、缩略语、专有名词首字母外，均小写
- 期刊名：各实词首字母大写
- 出版项：年、卷、期、页码**必须齐全**

## 十、LaTeX 实现要点

基于本规范的 `ctexart` 关键配置：

```latex
\documentclass[twocolumn,a4paper,10pt]{ctexart}

% 页面设置
\usepackage[top=2.2cm, bottom=2.2cm, left=1.8cm, right=1.8cm, columnsep=0.7cm]{geometry}

% 引言编号从 0 开始
\setcounter{section}{-1}
\section{引 言}

% 图：图字 6 号，中文，图随文后
% 表：三线表（booktabs），表内中文
% 公式：全文顺序编号，向量/矩阵黑斜体 \bm{}

% 参考文献：按引用顺序排列
\begin{thebibliography}{99}
\bibitem{key} 作者. 题名[J]. 刊名, 年, 卷(期): 页码.
\end{thebibliography}
```

### 常用包

```latex
\usepackage{amsmath, amssymb, bm}          % 数学 + 黑斜体
\usepackage{booktabs}                       % 三线表
\usepackage[colorlinks,linkcolor=black,citecolor=black,urlcolor=blue]{hyperref}
\usepackage{fancyhdr}                       % 页眉页脚
```

### 编译

```bash
xelatex -interaction=nonstopmode paper.tex  # 必须用 xelatex（中文支持）
latexmk -xelatex paper.tex                  # 推荐：自动处理交叉引用
```

---

> **与默认 ctexart 的关键差异**：
> 1. 引言编号为 0（`\setcounter{section}{-1}`）
> 2. 图/表/公式全文统一顺序编号，不以章节编号
> 3. 图字 6 号，**必须中文**，不得出现英文
> 4. 表中文字**必须中文**
> 5. 表内单位：全表一致的放右上角，不一致的归并于量名称
> 6. 正文后不要附录
> 7. 参考文献按引用顺序排列，15 条以上，英文≥2/3
> 8. 作者简介为必填项，刊登于文后
