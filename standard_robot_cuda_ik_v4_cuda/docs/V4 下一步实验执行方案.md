# 4. M2：Smoothness 候选解重排序

## 4.1 旧方案废弃说明

M0 中 Smoothness 直接加入 LM 残差导致：

```text
Strict SR ≈ 2%
pos_p95_all 数百 mm
```

说明 smoothness 不能直接主导位姿优化。

因此 M2 改为：

```text
先求解多个候选 IK 解
再在成功候选中按轨迹连续性重排序
```

核心原则：

```text
位姿成功优先，轨迹平滑其次。
```

---

## 4.2 新 Smoothness 方案

对每个轨迹点 `T_t`，使用 Sobol-K16 或 Sobol-K32 生成 K 个候选解：

```text
q_candidate[t, k]
pos_err[t, k]
rot_err[t, k]
limit_score[t, k]
loss_pose[t, k]
```

然后进行候选筛选和重排序。

---

## 4.3 候选选择优先级

不要用单一加权分数直接压过位姿误差。采用分级规则：

### 优先级 1：成功等级

按以下等级排序：

```text
Strict success > Medium success > Loose success > Failed
```

### 优先级 2：关节限位安全性

在同一成功等级内，优先选择：

```text
near_limit = False
limit_score 更小
```

### 优先级 3：轨迹连续性

在同一成功等级和相近 limit_score 下，选择：

```text
||q_candidate - q_prev|| 最小
```

### 优先级 4：位姿误差

如果 smoothness 接近，则选择 pose loss 更小者。

---

## 4.4 推荐 scoring 实现

可以先实现字典序选择，不要一开始复杂加权。

对每个候选构造排序键：

```python
success_rank = 0 if strict_success else 1 if medium_success else 2 if loose_success else 3
near_limit_rank = 1 if near_limit else 0
smooth_cost = norm(wrap_to_pi(q_candidate - q_prev)) ** 2
pose_cost = pos_err_m ** 2 + rot_err_rad ** 2

sort_key = (
    success_rank,
    near_limit_rank,
    smooth_cost,
    pose_cost
)
```

选择 `sort_key` 最小的候选。

注意：

```text
success_rank 必须排在 smooth_cost 前面。
```

否则会出现为了平滑而放弃位姿成功的错误。

---

## 4.5 q_prev 设置

第一个轨迹点：

```text
q_prev = zero_seed 或 V3 独立最优解
```

建议测试两种：

| 模式        | q_prev 初始化                   |
| --------- | ---------------------------- |
| init_zero | q_prev = zero_seed           |
| init_best | q_prev = 第一个点的最小 pose loss 解 |

推荐最终使用：

```text
init_best
```

从第二个轨迹点开始：

```text
q_prev = 上一个轨迹点最终选择的 q_best
```

## 5.2 轨迹生成要求

轨迹应由合法关节轨迹或合法末端轨迹生成，确保目标可达。

推荐方式：

1. 先生成一条连续关节空间轨迹 `q_gt[t]`；
2. 用 FK 生成 `T_target[t]`；
3. 求解器只能使用 `T_target[t]`，不能直接使用 `q_gt[t]`；
4. `q_gt[t]` 仅用于分析目标是否接近奇异、是否有分支跳变。
