# 图2：Block/Warp/Lane三级并行映射示意图 — 绘制描述词

## 一、图的目标与定位

本图展示CUDA Grid到Block到Warp到Lane的三级层次映射关系，以及每个Warp内线程的数学任务分工。这是理解本发明"单次kernel launch完成全部N个目标的全部DLS迭代"这一核心设计的关键图。

图类型：**层次映射示意图 + 任务分工表**（Hierarchical Mapping Diagram）

推荐绘图工具：**TikZ**（LaTeX，适合精确的层次结构图）或 **draw.io**（更易上手）

## 二、图的结构布局

建议采用**自上而下的层次展开布局**：Grid → Block → Warp → Lane，每一层展开为下一层的详细视图。

### 2.1 顶层：Grid层

**矩形框，标注**：

```
┌─────────────────────────────────────────────────┐
│  Grid = (N, 1, 1)                                │
│  N个Block，Block索引 b = blockIdx.x              │
│  每个Block对应一个IK目标 (T_tgt^(b))             │
│  各Block完全独立，无跨Block通信                   │
└─────────────────────────────────────────────────┘
```

从Grid框向下引出3条虚线箭头，分别指向3个示例Block（用不同的索引号展示），并在中间标注"..."表示共有N个。

### 2.2 第二层：Block层（选取其中一个Block放大展示）

**选取Block b（blockIdx.x = b）作为代表，放大为详细视图**。

```
┌─────────────────────────────────────────────────┐
│  Block b (blockIdx.x = b)                        │
│  128 threads = 4 Warps × 32 Lanes/Warp           │
│  共享内存: ~1,616 bytes                          │
│  寄存器: 94 regs/thread (NCU实测)                 │
│                                                  │
│  ┌──────────┬──────────┬──────────┬──────────┐  │
│  │  Warp 0  │  Warp 1  │  Warp 2  │  Warp 3  │  │

│  └──────────┴──────────┴──────────┴──────────┘  │
└─────────────────────────────────────────────────┘
```

Block框下方标注共享内存中各变量的大小和用途（以小型表格呈现）：

| 变量 | 大小 | 用途 |
|------|:----:|------|
| s_q[8] | 64 B | 当前关节角 |
| s_T[16], s_T_tgt[16] | 256 B | FK结果 + 目标位姿 |
| s_J[48] (PaddedMat6x8) | 384 B | Jacobian矩阵 |
| s_H[48] (PaddedMat6x8) | 384 B | 阻尼正规矩阵 |
| s_err[6], s_g[6], s_dq[6] | 144 B | 误差 / 梯度 / 增量 |
| 其他(scalars) | ~384 B | 收敛标志/迭代计数/阻尼/停滞等 |
| **总计** | **~1,616 B** | |

### 2.3 第三层：Warp层（核心！需要最大面积展示）

将4个Warp分别展开为独立的详细面板，每个Warp包含：

- Lane范围标签
- 任务名称
- 数学映射公式
- 并行粒度说明
- 颜色编码

**Warp 0 面板（绿色背景）**：

```
┌─────────────────────────────────────────────────┐
│  WARP 0 — 控制流 (Lanes 0–31)                    │
│  执行模式: Lane 0 串行执行，Lanes 1–31 等待      │
│                                                  │
│  Lane 0 执行的任务序列:                           │
│  ┌─────────────────────────────────────────┐    │
│  │ ① FK链式乘法 (forward_kinematics)        │    │
│  │    读取 __constant__ 内存参数             │    │
│  │    T_EE = Π (T_i⁰ · R(a_i, q_i)) · T_tcp│    │
│  │    运算量: ~450乘加 + 12三角函数/次       │    │
│  │                                          │    │
│  │ ② 位姿误差计算 (pose_error)              │    │
│  │    e_p = p^d - p(q), e_R = Log(R^d·R^T)∨│    │
│  │    e = [e_p; e_R] ∈ R⁶                   │    │
│  │                                          │    │
│  │ ③ LDLᵀ求解 (ldlt_solve_6x6)             │    │
│  │    H → L·D·Lᵀ → L·y=g → D·z=y → Lᵀ·x=z │    │
│  │    86次标量运算，全部寄存器内执行         │    │
│  │                                          │    │
│  │ ④ LM阻尼更新 (adaptive damping)          │    │
│  │    改进: λ*=0.7  退化: λ*=2.0            │    │
│  │    停滞>12: λ*=5.0                       │    │
│  │                                          │    │
│  │ ⑤ 收敛判定                               │    │
│  │    ‖e_p‖₂ < 0.03m AND θ_R < 0.5236rad   │    │
│  └─────────────────────────────────────────┘    │
└─────────────────────────────────────────────────┘
```

**Warp 1 面板（蓝色背景）**：

```
┌─────────────────────────────────────────────────┐
│  WARP 1 — 数值Jacobian (Lanes 32–63)             │
│  执行模式: 6路数据并行（Lanes 32–37 工作，      │
│            Lanes 38–63 空闲）                    │
│                                                  │
│  Lane 32+j (j=0..5) 负责 J 的第 j 列:            │
│                                                  │
│  ┌─────────────────────────────────────────┐    │
│  │ ① q_plus = q + ε·e_j   (ε = 1×10⁻⁶)    │    │
│  │ ② FK(q_plus) → T_plus                   │    │
│  │ ③ q_minus = q - ε·e_j                  │    │
│  │ ④ FK(q_minus) → T_minus                 │    │
│  │ ⑤ e_plus = pose_error(T_plus, T_tgt)    │    │
│  │ ⑥ e_minus = pose_error(T_minus, T_tgt)  │    │
│  │ ⑦ J[:,j] = (e_plus - e_minus) / (2ε)   │    │
│  └─────────────────────────────────────────┘    │
│                                                  │
│  ⚡ 6路并行: 12次FK计算压缩为≈2次FK延迟          │
│                                                  │
│  6列输出布局:                                     │
│  ┌───┬───┬───┬───┬───┬───┐                      │
│  │J:0│J:1│J:2│J:3│J:4│J:5│ (各6元素，共36)      │
│  └───┴───┴───┴───┴───┴───┘                      │
└─────────────────────────────────────────────────┘
```

**Warp 2 面板（橙色背景）**：

```
┌─────────────────────────────────────────────────┐
│  WARP 2 — H矩阵与g向量构造 (Lanes 64–95)          │
│  执行模式: 36路数据并行 (Lanes 64–99 工作,       │
│            Lanes 100–127 可复用部分)              │
│                                                  │
│  Lane 64+(i×6+j) (i,j=0..5) 负责 H[i][j]:        │
│                                                  │
│  ┌─────────────────────────────────────────┐    │
│  │ H[i][j] = Σ_{k=0..5} w_k²·J[k][i]·J[k][j]│   │
│  │ 每个Lane执行6项加权内积（FP64累加）       │    │
│  │ if i==j: H[i][i] += λ²  (阻尼项)         │    │
│  └─────────────────────────────────────────┘    │
│                                                  │
│  36元素输出矩阵 H (6×6对称):                      │
│  ┌────┬────┬────┬────┬────┬────┐                │
│  │H₀₀ │H₀₁ │H₀₂ │H₀₃ │H₀₄ │H₀₅ │                │
│  │H₁₀ │H₁₁ │ ...         │H₁₅ │                │
│  │ ...                                  │        │
│  │H₅₀ │ ...              │H₅₅ │                │
│  └────┴────┴────┴────┴────┴────┘                │
│                                                  │
│  ⚠ 此阶段若无PaddedMat6x8, 列访问导致           │
│    2–3路Bank冲突（详见Figure 3）                 │
└─────────────────────────────────────────────────┘
```

**Warp 3 面板（红色背景）**：

```
┌─────────────────────────────────────────────────┐
│  WARP 3 — 关节更新 & 限位投影 (Lanes 96–127)      │
│  执行模式: 6路数据并行 (Lanes 96–101 工作,       │
│            Lanes 102–127 空闲)                    │
│                                                  │
│  Lane 96+i (i=0..5) 负责第 i 个关节:              │
│                                                  │
│  ┌─────────────────────────────────────────┐    │
│  │ ① 步长检查: α = min(1.0, 0.25/‖Δq‖_∞)  │    │
│  │ ② 步长裁剪(A6): ‖Δq‖_∞>0.35 → 等比缩放  │    │
│  │ ③ 限位投影:                               │    │
│  │    q_i^(k+1) = clamp(q_i^(k)+α·Δq_i,     │    │
│  │                      q_imin, q_imax)      │    │
│  │ ④ 分支对齐(A6): diff→atan2归一化±2π修正  │    │
│  └─────────────────────────────────────────┘    │
│                                                  │
│  6个关节并行更新:                                 │
│  ┌───┬───┬───┬───┬───┬───┐                      │
│  │q₁ │q₂ │q₃ │q₄ │q₅ │q₆ │ (各1个Lane)          │
│  └───┴───┴───┴───┴───┴───┘                      │
└─────────────────────────────────────────────────┘
```

## 三、颜色编码方案

| Warp | 颜色 | 色号 | 含义 |
|:----:|:----:|:----:|------|
| W0 | 绿色 | #4CAF50 / #C8E6C9 | 控制流（串行逻辑） |
| W1 | 蓝色 | #2196F3 / #BBDEFB | 数据并行（Jacobian列） |
| W2 | 橙色 | #FF9800 / #FFE0B2 | 数据并行（矩阵元素） |
| W3 | 红色 | #F44336 / #FFCDD2 | 数据并行（关节更新） |
| 空闲Lane | 灰色 | #E0E0E0 | 未使用的线程 |
| 同步点 | 紫色虚线 | #9C27B0 | __syncthreads() barrier |

## 四、尺寸与布局建议

- 画布：横向A3或16:9（约1800×1000像素等效）
- Grid层：顶部5-8%高度
- Block层：10-15%高度
- Warp层（4个面板）：中部2×2或1×4排列，占55-65%高度
  - 建议采用1×4水平排列，每个Warp面板等宽
- 同步控制条：底部10-12%高度
- 每个Warp面板内部的任务列表采用编号列表，字体10-11pt

## 五、特别注意事项

1. **W0的Lane 0** 必须用特殊标记（如加粗边框或星号），因为它是整个DLS迭代的唯一控制线程
2. **空闲Lane**（W1的Lanes 38-63、W3的Lanes 102-127）需要用灰色标注，表示这些线程不参与计算
3. **Warp 2的36路并行**需要体现"每个Lane负责H的一个元素(i,j)"这一关键映射
4. 4个同步点（__syncthreads()）之间的数据依赖关系用紫色虚线箭头表示
5. 底部控制条应清晰展示"单次Kernel Launch"这一关键设计特征
6. 可选的补充标注：在每个Warp面板角落用小字标注NCU实测的warp stall原因（如W0: "stall_inst_fetch", W1: "stall_exec_dependency"等）
