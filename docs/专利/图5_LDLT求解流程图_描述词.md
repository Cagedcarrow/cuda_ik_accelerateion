# 图5：LDLᵀ分解求解流程图 — 绘制描述词

## 一、图的目标与定位

本图展示6×6对称正定矩阵的LDLᵀ分解求解四阶段流程：从H矩阵和g向量输入，经过LDLᵀ分解（阶段一）、前代求解（阶段二）、对角缩放（阶段三）、回代求解（阶段四），最终输出Δq解向量。图中标注每阶段的运算量、FMA映射统计和关键数值特性。

图类型：**算法流程图**（Algorithm Flowchart）

推荐绘图工具：**TikZ**（LaTeX，适合精确的算法流程图和数学公式）或 **draw.io**（适合快速绘制）

## 二、图的结构布局

建议采用**自上而下的四阶段纵向流程**，每个阶段为一个横向面板。

### 2.1 顶部：输入数据框

```
┌─────────────────────────────────────────────────────────┐
│  输入                                                      │
│  ┌──────────────────────┐  ┌─────────────────────────┐   │
│  │ H ∈ R^{6×6}          │  │ g ∈ R⁶                  │   │
│  │ H = JᵀW²J + λ²I     │  │ g = JᵀW²e              │   │
│  │ 对称正定 (SPD)        │  │ 梯度向量                 │   │
│  │ 36个FP64元素          │  │ 6个FP64元素              │   │
│  └──────────────────────┘  └─────────────────────────┘   │
│                                                          │
│  数据驻留: 全部在GPU寄存器中 (96个FP64元素 = 768 bytes)    │
│  运算环境: Lane 0 (Warp 0), 单线程串行执行                │
└─────────────────────────────────────────────────────────┘
```

### 2.2 阶段一：LDLᵀ分解 (Decomposition)

**面板背景色**：浅蓝色 (#E3F2FD)

```
┌─────────────────────────────────────────────────────────────┐
│  阶段一: LDLᵀ分解  H = L·D·Lᵀ                               │
│                                                             │
│  核心: 无需选主元 (λ²I保证SPD), 无需平方根 (区别于Cholesky)   │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐ │
│  │ 步骤1a: 对角元更新 — D[j] = A[j][j] - Σ_{k<j} L[j][k]²·D[k] │
│  │                                                       │ │
│  │   for j = 0 to 5:                                     │ │
│  │     D[j] = A[j][j]                                    │ │
│  │     for k = 0 to j-1:                                 │ │
│  │       D[j] -= L[j][k] * L[j][k] * D[k]                │ │
│  │                                                       │ │
│  │   运算量: 15次乘加 (全部可映射为FMA)                     │ │
│  │   数据依赖: D[j] 依赖 D[0..j-1], L[j][0..j-1]          │ │
│  └───────────────────────────────────────────────────────┘ │
│                          ↓                                  │
│  ┌───────────────────────────────────────────────────────┐ │
│  │ 步骤1b: 非对角元更新 — L[i][j] = (A[i][j] - Σ_{k<j} L[i][k]·L[j][k]·D[k]) / D[j] │
│  │                                                       │ │
│  │   for j = 0 to 5:                                     │ │
│  │     L[j][j] = 1.0                                     │ │
│  │     for i = j+1 to 5:                                 │ │
│  │       L[i][j] = A[i][j]                               │ │
│  │       for k = 0 to j-1:                               │ │
│  │         L[i][j] -= L[i][k] * L[j][k] * D[k]           │ │
│  │       L[i][j] /= D[j]  ← 条件数敏感!                  │ │
│  │                                                       │ │
│  │   运算量: 20次乘加 (可FMA) + 15次除法                    │ │
│  └───────────────────────────────────────────────────────┘ │
│                                                             │
│  阶段一输出: L (单位下三角6×6), D (对角6)                    │
│  存储: L[6][6] + D[6] = 42个FP64元素 (全寄存器)              │
└─────────────────────────────────────────────────────────────┘
```

**阶段一右侧标注框**：

```
┌───────────────────────────────┐
│ 为何选择LDLᵀ而非Cholesky?    │
│                               │
│ Cholesky: H = L·Lᵀ            │
│ 需要6次平方根运算              │
│ GPU上sqrt吞吐 ≈ FMA的1/4~1/8  │
│                               │
│ LDLᵀ: H = L·D·Lᵀ             │
│ 无平方根 → 全部FMA和除法      │
│ 更适合GPU的指令组合            │
│                               │
│ 为何无需选主元?                │
│ λ²I保证H严格正定               │
│ → D[j] > 0 始终成立           │
│ → 无需行交换                   │
└───────────────────────────────┘
```

### 2.3 阶段二：前代求解 (Forward Substitution)

**面板背景色**：浅绿色 (#E8F5E9)

```
┌─────────────────────────────────────────────────────────────┐
│  阶段二: 前代求解  L·y = g                                   │
│                                                             │
│  L 为单位下三角矩阵 (L[i][i] = 1)                             │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐ │
│  │ for i = 0 to 5:                                       │ │
│  │   y[i] = g[i]                                         │ │
│  │   for k = 0 to i-1:                                   │ │
│  │     y[i] -= L[i][k] * y[k]                            │ │
│  │                                                       │ │
│  │ 运算量: 15次乘减 (全部可映射为FMA)                       │ │
│  │ 数据依赖: y[i] 依赖 y[0..i-1] (顺序依赖, 不可并行)      │ │
│  └───────────────────────────────────────────────────────┘ │
│                                                             │
│  示意图 (上三角零元素以灰色表示):                               │
│  ┌───┬───┬───┬───┬───┬───┐    ┌───┐   ┌───┐               │
│  │ 1 │   │   │   │   │   │    │y₀│   │g₀│               │
│  │L₁₀│ 1 │   │   │   │   │    │y₁│   │g₁│               │
│  │L₂₀│L₂₁│ 1 │   │   │   │ ×  │y₂│ = │g₂│               │
│  │L₃₀│L₃₁│L₃₂│ 1 │   │   │    │y₃│   │g₃│               │
│  │L₄₀│L₄₁│L₄₂│L₄₃│ 1 │   │    │y₄│   │g₄│               │
│  │L₅₀│L₅₁│L₅₂│L₅₃│L₅₄│ 1 │    │y₅│   │g₅│               │
│  └───┴───┴───┴───┴───┴───┘    └───┘   └───┘               │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 阶段三：对角缩放 (Diagonal Scaling)

**面板背景色**：浅橙色 (#FFF3E0)

```
┌─────────────────────────────────────────────────────────────┐
│  阶段三: 对角缩放  D·z = y  →  z = D⁻¹·y                      │
│                                                             │
│  D为对角矩阵, 因此每个方程完全解耦                              │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐ │
│  │ for i = 0 to 5:                                       │ │
│  │   y[i] /= D[i]                                        │ │
│  │                                                       │ │
│  │ 运算量: 6次除法 (SFU特殊功能单元执行)                     │ │
│  │ 无数据依赖 (6个元素完全独立, 可指令级并行)                │ │
│  └───────────────────────────────────────────────────────┘ │
│                                                             │
│  示意图:                                                     │
│  ┌───────┐⁻¹  ┌───┐   ┌───┐                                │
│  │ D₀    │    │y₀│   │z₀│                                │
│  │   D₁  │ ×  │y₁│ = │z₁│                                │
│  │     D₂│    │y₂│   │z₂│  (y被就地覆盖为z)                │
│  │      D│    │y₃│   │z₃│                                │
│  │       D│   │y₄│   │z₄│                                │
│  │        D│  │y₅│   │z₅│                                │
│  └───────┘    └───┘   └───┘                                │
└─────────────────────────────────────────────────────────────┘
```

**阶段三右侧标注框**：

```
┌───────────────────────────────┐
│ 条件数问题                     │
│                               │
│ 若H的条件数大, D中的对角元     │
│ 可能量级悬殊 (如1e+3 vs 1e-6) │
│                               │
│ → 除法 D_min 会被放大误差      │
│ → 这是保留FP64的关键原因!      │
│                               │
│ λ²I正则化的作用:               │
│ → 提升H的最小特征值            │
│ → 改善条件数                   │
│ → 间接稳定对角缩放阶段         │
└───────────────────────────────┘
```

### 2.5 阶段四：回代求解 (Backward Substitution)

**面板背景色**：浅紫色 (#F3E5F5)

```
┌─────────────────────────────────────────────────────────────┐
│  阶段四: 回代求解  Lᵀ·Δq = z                                 │
│                                                             │
│  Lᵀ 为上三角矩阵 (L为单位下三角的转置)                         │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐ │
│  │ for i = 5 down to 0:                                  │ │
│  │   dq[i] = y[i]       // y已被阶段三缩放为z             │ │
│  │   for j = i+1 to 5:                                   │ │
│  │     dq[i] -= L[j][i] * dq[j]                          │ │
│  │                                                       │ │
│  │ 运算量: 15次乘减 (全部可映射为FMA)                       │ │
│  │ 数据依赖: dq[i] 依赖 dq[i+1..5] (逆序依赖, 不可并行)    │ │
│  └───────────────────────────────────────────────────────┘ │
│                                                             │
│  示意图:                                                     │
│  ┌───┬───┬───┬───┬───┬───┐    ┌────┐   ┌───┐              │
│  │ 1 │L₁₀│L₂₀│L₃₀│L₄₀│L₅₀│    │Δq₀│   │z₀│              │
│  │   │ 1 │L₂₁│L₃₁│L₄₁│L₅₁│    │Δq₁│   │z₁│              │
│  │   │   │ 1 │L₃₂│L₄₂│L₅₂│ ×  │Δq₂│ = │z₂│              │
│  │   │   │   │ 1 │L₄₃│L₅₃│    │Δq₃│   │z₃│              │
│  │   │   │   │   │ 1 │L₅₄│    │Δq₄│   │z₄│              │
│  │   │   │   │   │   │ 1 │    │Δq₅│   │z₅│              │
│  └───┴───┴───┴───┴───┴───┘    └────┘   └───┘              │
└─────────────────────────────────────────────────────────────┘
```

### 2.6 底部：输出与汇总

```
┌─────────────────────────────────────────────────────────────┐
│  输出: Δq ∈ R⁶ (关节增量向量, FP64精度)                        │
│  后续: Δq → FP32转换 → 关节更新 q^(k+1) = clamp(q^k + α·Δq)  │
├─────────────────────────────────────────────────────────────┤
│  运算量汇总:                                                  │
│  ┌──────────┬────────┬──────────┬──────────┐                │
│  │   阶段   │  运算  │ 可FMA映射 │ 数据类型 │                │
│  ├──────────┼────────┼──────────┼──────────┤                │
│  │ 1a 对角  │ 15 mul-add │  15/15   │ FP64 FMA │            │
│  │ 1b 非对角│ 20 mul-add + 15 div │ 20/20 15/0│ FP64     │  │
│  │ 2  前代  │ 15 mul-sub │  15/15   │ FP64 FMA │            │
│  │ 3  对角  │  6 div     │   0/6    │ FP64 SFU │            │
│  │ 4  回代  │ 15 mul-sub │  15/15   │ FP64 FMA │            │
│  ├──────────┼────────┼──────────┼──────────┤                │
│  │  总计    │ 86 次     │ 65/86    │ 全部FP64 │              │
│  │          │          │ (75.6%)  │          │              │
│  └──────────┴────────┴──────────┴──────────┘                │
│                                                             │
│  编译优化:                                                   │
│  → NVCC #pragma unroll 全部循环展开                          │
│  → 消除分支预测失败 + 循环控制开销                            │
│  → 编译器ILP: 无数据依赖的标量运算调度至同一发射周期           │
│                                                             │
│  实测性能:                                                   │
│  → 单次LDLᵀ求解延迟: ~0.05-0.10 μs                          │
│  → 寄存器使用: ~192个32位寄存器 (等效96个FP64元素)            │
│  → Local Memory Spill: 0 (NCU确认)                         │
│  → 全局内存访问: 0 (全部数据在寄存器中)                       │
│  → 共享内存访问: 0 (求解阶段本身)                            │
└─────────────────────────────────────────────────────────────┘
```

## 四、尺寸建议

- 画布：纵向A4或16:9（约1400×1800像素等效，纵向布局）
- 输入框: 8%高度
- 阶段一: 28%高度（最大，最复杂）
- 阶段二: 14%高度
- 阶段三: 12%高度
- 阶段四: 14%高度
- 输出汇总: 24%高度

## 五、特别注意事项

1. **阶段一中的除法操作必须用红色标签突出**——`L[i][j] /= D[j]` 是条件数敏感的关键操作
2. **阶段三虽然运算最少（仅6次除法），但必须用橙色突出**——对角缩放是精度损失的高风险环节
3. 每个阶段右侧的"示意图"展示矩阵结构和数据流方向（前代是从上到下，回代是从下到上）
4. 底部汇总表中"可FMA映射"列使用小进度条图标，直观展示75.6%的FMA利用率
5. "Local Memory Spill: 0"和"全局内存访问: 0"用绿色对勾标注，这是关键性能指标
6. 四个阶段之间的箭头应标注输出数据类型（如"L[6][6], D[6]"、"y[6]"等）
7. 可在阶段一框内添加一个微缩的3×3 LDLᵀ示例，展示L和D矩阵的实际填充模式（下三角形状）
