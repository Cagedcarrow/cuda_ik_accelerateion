# 图6：B0-B6消融实验效果对比图 — 绘制描述词

## 一、图的目标与定位

本图以分组柱状图的形式展示B0至B6七级消融配置在不同批量规模（N=100/500/1000/5000）下的吞吐量（Query Throughput, targets/s），直观揭示每项技术方案（常量内存、PaddedMat6x8、自适应阻尼、步长钳位+分支对齐、混合精度、CUDA Graph）对批量IK吞吐性能的独立贡献。

图类型：**分组柱状图（Grouped Bar Chart）**，建议使用对数纵轴

推荐绘图工具：**Matplotlib**（Python，`matplotlib.pyplot.bar` 或 `seaborn.barplot`，适合精确的数据可视化）

## 二、图的结构

### 2.1 坐标轴

- **X轴**：消融级别 B0, B1, B2, B3, B4, B5, B6（共7组）
- **Y轴**：Query Throughput (targets/s)，**建议使用对数刻度（log scale）**——因为N=100和N=5000的吞吐值跨度约1-2个数量级
- **分组**：每个消融级别内包含4根柱子，对应N=100/500/1000/5000

### 2.3 绘制参数

```python
# Matplotlib示例代码框架
import matplotlib.pyplot as plt
import numpy as np

# 消融级别标签
ablation_labels = ['B0\n(baseline)', 'B1\n+ConstMem', 'B2\n+PaddedMat',
                   'B3\n+Adaptive\nDamping', 'B4\n+StepClamp\n+BranchAlign',
                   'B5\n+Mixed\nPrecision', 'B6\n+CUDA\nGraph']

# 批量规模
N_values = [100, 500, 1000, 5000]

# 吞吐数据 (targets/s) — 按 [B0, B1, B2, B3, B4, B5, B6] 顺序, 每个含4个N值
throughput = {
    'B0': [15498, 8563, 1849, 5009],
    'B1': [15898, 8639, 1881, 5084],
    'B2': [16239, 8792, 1913, 5149],
    'B3': [21768, 33211, 35901, 38320],
    'B4': [17612, 25457, 28790, 32822],
    'B5': [107250, 149787, 140246, 180962],
    'B6': [111235, 150966, 140815, 181290],
}

# 收敛率数据（用于气泡叠加或颜色编码）
conv_rate = {
    'B0': [1.000, 0.976, 0.852, 0.834],
    'B1': [1.000, 0.976, 0.852, 0.834],
    'B2': [1.000, 0.976, 0.852, 0.834],
    'B3': [1.000, 0.996, 0.994, 1.000],
    'B4': [1.000, 0.998, 0.992, 0.994],
    'B5': [1.000, 0.998, 0.999, 0.9998],
    'B6': [1.000, 0.998, 0.999, 0.9998],
}

x = np.arange(len(ablation_labels))
width = 0.2  # 柱宽

fig, ax = plt.subplots(figsize=(16, 8))

colors = ['#90CAF9', '#64B5F6', '#42A5F5', '#1E88E5']  # N=100,500,1000,5000

for i, (N, color) in enumerate(zip(N_values, colors)):
    offset = (i - 1.5) * width
    values = [throughput[abl][i] for abl in ['B0','B1','B2','B3','B4','B5','B6']]
    bars = ax.bar(x + offset, values, width, label=f'N={N}', color=color, edgecolor='white')

    # 在B5/B6柱上标注数值
    for bar, val in zip(bars, values):
        if val > 50000:  # 仅在高吞吐柱上标注
            ax.text(bar.get_x() + bar.get_width()/2., bar.get_height(),
                    f'{val:,}', ha='center', va='bottom', fontsize=8, rotation=90)

ax.set_yscale('log')
ax.set_ylabel('Query Throughput (targets/s, log scale)', fontsize=13)
ax.set_xticks(x)
ax.set_xticklabels(ablation_labels, fontsize=11)
ax.legend(fontsize=12, loc='upper left')
ax.grid(axis='y', alpha=0.3)

# 添加关键提升标注箭头
# B2→B3 收敛率恢复
ax.annotate('ConvRate 83.4%→100%\n@N=5000',
            xy=(3, 38320), xytext=(2.5, 80000),
            arrowprops=dict(arrowstyle='->', color='green', lw=2),
            fontsize=9, color='green', fontweight='bold')

# B3→B4 吞吐下降
ax.annotate('14-20% throughput drop\nNo conv. benefit',
            xy=(4, 32822), xytext=(4.5, 50000),
            arrowprops=dict(arrowstyle='->', color='red', lw=2),
            fontsize=9, color='red')

# B4→B5 混合精度大幅提升
ax.annotate('148-154% throughput gain\nMixed Precision',
            xy=(5, 180962), xytext=(5.5, 250000),
            arrowprops=dict(arrowstyle='->', color='blue', lw=2),
            fontsize=9, color='blue', fontweight='bold')

# B5→B6 CUDA Graph微增
ax.annotate('<3.7% gain\nCUDA Graph',
            xy=(6, 181290), xytext=(6.3, 200000),
            arrowprops=dict(arrowstyle='->', color='gray', lw=1.5),
            fontsize=9, color='gray')

plt.tight_layout()
```

### 2.4 附加建议：第二Y轴展示收敛率

在主柱状图右侧添加第二Y轴，以折线图或散点图形式展示各配置在N=5000时的收敛率（ConvRate），使读者同时看到吞吐量和收敛率的trade-off：

```python
ax2 = ax.twinx()
conv_n5000 = [conv_rate[abl][3] for abl in ['B0','B1','B2','B3','B4','B5','B6']]
ax2.plot(x, conv_n5000, 'D-', color='darkred', linewidth=2, markersize=8, label='ConvRate @N=5000')
ax2.set_ylabel('Convergence Rate @ N=5000', fontsize=13, color='darkred')
ax2.set_ylim(0.8, 1.01)
ax2.legend(fontsize=12, loc='upper right')
```

### 2.5 图底部：关键洞察标注框

在柱状图下方添加一个文本注释框，总结消融实验的核心发现：

```
┌──────────────────────────────────────────────────────────────────┐
│  关键洞察:                                                        │
│                                                                  │
│  ① B0→B2 (ConstMem + PaddedMat): 仅~5%吞吐提升 (N=100),          │
│     N≥500时可忽略 → 内存层次优化收益有限                           │
│                                                                  │

│  ③ B3→B4 (步长钳位+分支对齐): 14-20%吞吐下降, 无收敛收益          │
```

## 五、替代可视化方案

如果需要强调"各项优化的累积贡献"，可以用**堆叠水平瀑布图（Waterfall Chart）**替代：

- 起始点为B0在N=5000的吞吐量（5,009 t/s）
- 每个消融步骤的增量显示为水平浮动条形
  - B1:+75, B2:+65 → 小增量
  - B3:+33,171 → 大增量（自适应阻尼）
  - B4:-5,498 → 负增量（步长钳位开销）
  - B5:+148,140 → 极大增量（混合精度）
  - B6:+328 → 小增量（CUDA Graph）
- 终点为B6的吞吐量（181,290 t/s）
- 适合在PPT或口头报告中展示"优化历程"

## 六、特别注意事项

1. **对数纵轴必须明确标注**——读者可能误以为B5只是B0的几倍提升（实际是36倍@N=100）
2. **B5的柱子应该是最突出的**——它在所有N值下都显著高于B0-B4
3. **B3→B4的吞吐下降**需要用红色箭头明确标注，因为这是唯一的"负优化"
4. **B6 vs B5的微小差距**需要在柱顶用数字标签标注，否则肉眼几乎无法区分
5. **收敛率折线**（第二Y轴）需要与柱状图的颜色区分开——建议使用深红色，且使用菱形标记点
6. 图表标题建议为："B0-B6消融实验：各优化策略对批量IK吞吐的独立贡献"
7. 在B3、B4、B5柱子旁边用小字标注ConvRate数值（特别是B0-B2在N=5000时的83.4%低收敛率）
8. 如果空间允许，可在每个柱组上方标注与B0的相对加速比（如"×21.4 @ B5 N=100"）
