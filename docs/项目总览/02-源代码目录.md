## 2. CUDA Kernel 源码 `src/cuda/`

### 2.1 `cuda_ik_6dof.cu` — 核心 kernel 文件（~1530 行）

**绝对路径：** `standard_robot_cuda_ik/src/cuda/cuda_ik_6dof.cu`

**包含 5 个 GPU kernel：**

| Kernel | 用途 | 关键特征 |
|--------|------|---------|
| `ik_batch_solve` | 主批量 IK 求解（FP64） | 固定阻尼 + 步长钳位 + 收敛检测 |
| `ik_batch_solve_mixed` | 混合精度批量 IK（**主配置 B5**） | FP32 FK/Jacobian + FP64 LDLT |
| `ik_batch_solve_multi` | 多样本批量 IK | 每目标多初始种子 |
| `compute_continuity_cost` | 连续性代价计算 | 相邻目标关节平滑性 |
| `filter_topk_per_target` | Top-K 过滤 | 共享内存 bitonic sort |

**消融变体：**
- `ik_batch_solve_ablation_A0` — ABLATION_LEVEL=0（B0 基线：global memory, 无优化）
- ABLATION_LEVEL 宏通过 CMake 编译时定义控制功能开关

**主机端 launcher 函数：**
- `launch_batch_ik()` — 标准启动
- `launch_batch_ik_mixed()` — 混合精度启动（B5）
- `launch_batch_ik_graph()` — CUDA Graph replay 启动（B6）
- 所有 launcher 在 `cuda_ik_6dof.h` 中声明

**DLS 迭代 pipeline（代码行号参考）：**
```
2a. 前向运动学 FK          (threadIdx.x == 0)
2b. 位姿误差计算            (threadIdx.x == 0)
2c. 收敛判定               (threadIdx.x == 0)
2d. 数值 Jacobian          (threadIdx.x < 6)    → 中心差分，ε=1e-6
2e. 自适应阻尼              (threadIdx.x == 0)    → ABLATION_LEVEL >= 5
2f. H 矩阵构造             (threadIdx.x < 36)   → 全部 36 元素，row=tid/6, col=tid%6
2g. 梯度 g 构造            (threadIdx.x < 6)    → g = J^T W^2 e
2h. LDLT 求解              (threadIdx.x == 0)   → 寄存器级 6×6
2i. 步长钳位               (threadIdx.x == 0)   → 0.35 rad, ABLATION_LEVEL >= 6
2j. 关节更新 + 限位投影     (threadIdx.x < 6)
```

**关键代码常量：**

| 常量 | 值 | 位置（代码行） |
|------|-----|-------------|
| 步长钳位阈值 | 0.35 rad | 275-280 (ik_batch_solve) |
| 阻尼加对角线 | `sum += s_lambda`（单次 λ） | 244 |
| H 构造线程数 | 36 (`threadIdx.x < 36`) | 233 |
| 数值差分步长 | ε = 1e-6 | 161 |
| Jacobian 定义 | FK 中心差分 (∂x/∂q) | 170-198 |
| 线程映射 | flat threadIdx.x（非 warp 边界） | 全局 |

### 2.2 `cuda_utilities.cuh` — 设备端工具函数（~448 行）

**绝对路径：** `standard_robot_cuda_ik/src/cuda/cuda_utilities.cuh`

| 模块 | 关键函数/结构 | 用途 |
|------|-------------|------|
| PaddedMat6x8 | `struct PaddedMat6x8` | 共享内存矩阵包装，stride=8 消除 Bank 冲突 |
| FloatPaddedMat6x8 | `struct FloatPaddedMat6x8` | FP32 版本（混合精度用） |
| FK 计算 | `forward_kinematics()` | Rodrigues 公式，读取 constant memory |
| FK 计算（A0） | `forward_kinematics_global()` | 从 global memory 读取参数（B0 基线） |
| 旋转矩阵 | `build_rotation_matrix()` | 轴角 → 3×3 旋转矩阵 |
| 矩阵乘法 | `mat44_mul()` | 4×4 齐次矩阵乘法 |
| 位姿误差 | `pose_error()` | 位置误差 + 姿态 geodesic 距离 |
| LDLT 求解 | `ldlt_solve_6x6()` | 寄存器级 6×6 LDLᵀ，86 次标量运算 |
| 数学工具 | `cuda_wrap()`, `cuda_clamp()`, `cuda_norm6()` | 角度 wrap、限位、向量范数 |

**常量内存声明（7 个 `__constant__` 数组，总计 ~1,160 bytes）：**

| 数组 | 大小 | 内容 |
|------|------|------|
| `c_segment_origins` | 96 doubles | DH 参数原点 |
| `c_segment_axes` | 18 doubles | DH 参数轴 |
| `c_q_index` | 6 ints | 关节索引映射 |
| `c_T_wrist3_to_tcp` | 16 doubles | 腕部到 TCP 变换 |
| `c_joint_limits` | 12 doubles | 关节限位 [lo, hi] × 6 |
| `c_weight_schedule` | 24 doubles | 误差权重（4 level × 6 维） |
| `c_lambda_params` | 4 doubles | 阻尼参数 [base, far, floor, scale] |

### 2.3 `cuda_benchmark_runner.cu` — 主机端 benchmark 驱动（~483 行）

**绝对路径：** `standard_robot_cuda_ik/src/cuda/cuda_benchmark_runner.cu`

功能：
- C++ `main()` 入口，解析命令行参数（N, repeat, warmup, threshold, level）
- 从 binary 文件加载目标位姿和种子
- 三层计时：`kernel_time_only`, `gpu_end_to_end_time`, `host_api_total_time`
- CUDA event 精确计时（`cudaEventElapsedTime`）
- CUDA Graph support（B6, `cudaGraphLaunch`）
- 统计输出：mean, std, P50/P95/P99, 95% CI
- FK 验证模式：对比 GPU FK 与 CPU 参考
- 全局内存模式：A0 消融用（不依赖 constant memory）

**输出格式（stdout 解析）：**
```
kernel_time_only_ms: 0.890
gpu_end_to_end_time_ms: 1.245
host_api_total_time_ms: 2.103
throughput_targets_per_sec: 112414
converged_count: 100
avg_pos_error_mm: 2.3
avg_orient_error_deg: 0.8
avg_iterations: 14.47
```

## 4. Python Benchmark 框架 `benchmark/`

### 4.1 核心框架

| 文件 | 用途 |
|------|------|
| `common.py` | **共享基础设施**：`BenchmarkResult` dataclass、收敛判定 `mark_convergence()`、阈值三档定义、数据加载 `load_robot_records()`/`load_seed_values()`、JSON/CSV 持久化 |
| `run_all.py` | **统一入口**：`--solver all/cuda/curobo/kdl/pyroki/numeric_dls`，生成 Markdown 报告 + JSON 摘要 |

### 4.2 求解器 Wrapper

| 文件 | 求解器 | 计时方式 | 备注 |
|------|--------|---------|------|
| `bench_cuda_6dof.py` | CUDA B5 | `subprocess.run()` 调用 C++ 二进制，解析 stdout | weight_level=2, max_iter=160 |
| `bench_curobo.py` | NVIDIA cuRobo | `time.perf_counter()` + `torch.cuda.synchronize()` | PyTorch GPU IK，num_seeds=1 |
| `bench_kdl.py` | Orocos KDL | `time.perf_counter()` per-target 串行 | C++ CPU, max 160 iter |
| `bench_pyroki.py` | PyRoki (JAX) | `time.perf_counter()` per-target | JAX GPU, JIT warmup excluded |
| `bench_numeric_dls.py` | NumPy DLS | `time.perf_counter()` per-target 串行 | Python CPU, max 100 iter |

### 4.3 辅助脚本

| 文件 | 用途 |
|------|------|
| `compare_paper_data.py` | **论文数据一致性检查**：硬编码论文数值 vs 最新 benchmark 实测，计算 % 差异 |
| `compare_results.py` | 通用结果对比 |
| `run_curobo_combo.py` | cuRobo 三档阈值组合扫描 |
| `run_b5_ablation.sh` | **消融批量执行**：映射 B0=A0, B1=A1, B2=A2, B3=A5, B4=A6, B5=A7, B6=A8 |
