## 2. 论文里的 DLS 符号又残留旧错误

论文中仍然出现：

> J 为位姿误差对关节角的雅可比矩阵，且 e(q+Δq)≈e(q)+JΔq。

这和你后面专利中已经修正的体系冲突。

你现在应该统一为：

```math
J=\frac{\partial x}{\partial q}
```

而不是：

```math
J=\frac{\partial e}{\partial q}
```

正确推导应写成：

```math
x(q+\Delta q)\approx x(q)+J\Delta q
```

```math
e(q+\Delta q)=x^d-x(q+\Delta q)\approx e(q)-J\Delta q
```

DLS 目标函数：

```math
\min_{\Delta q}\|W(e-J\Delta q)\|_2^2+\lambda^2\|\Delta q\|_2^2
```

正规方程：

```math
(J^TW^2J+\lambda^2I)\Delta q=J^TW^2e
```

数值 Jacobian：

```math
J_{:,j}=\frac{x(q+\varepsilon e_j)-x(q-\varepsilon e_j)}{2\varepsilon}
```

不要再写：

```math
\frac{e(q+\varepsilon e_j)-e(q-\varepsilon e_j)}{2\varepsilon}
```

# 二、专利仍有 3 个必须修的问题

## 1. 专利里的 λ 和 λ² 又写错了

专利最新版本中已经把 J 定义成了 `∂x/∂q`，这点是对的。

但是它又写成：

```text
min ||W(e-JΔq)||² + λ||Δq||²
```

以及：

```text
(JᵀW²J + λI)Δq = JᵀW²e
```

这不严谨。标准 DLS 应该是：

```math
\min_{\Delta q}\|W(e-J\Delta q)\|_2^2+\lambda^2\|\Delta q\|_2^2
```

```math
(J^TW^2J+\lambda^2I)\Delta q=J^TW^2e
```

如果你坚持把 λ 定义为“已经平方后的阻尼量”，那变量名应改成 μ，而不是 λ。

## 推荐统一

```text
λ 表示阻尼系数；
H 对角线加 λ²；
伪代码中写 s_lambda * s_lambda。
```

---

## 2. 专利伪代码仍写 `sum += s_lambda`

专利伪代码中仍有：

sum += s_lambda   // H_ii += λ
```

sum += s_lambda * s_lambda   // H_ii += λ²

λ‖Δq‖²

全部改成：

λ²I
λ²‖Δq‖²
```

## 3. 专利里又回到了 “H 的 M² 个元素并行构造”

专利中写：

> 正规矩阵构造线程束负责 H 的全部 M² 个元素，6DOF 时 36 个线程各自负责 H 的一个元素。

这个写法在专利里也不建议保留。

原因有两个：

第一，6DOF 的 36 个元素超过单 warp 32 lane，和“线程束分工”表述冲突。

第二，H 是对称矩阵，写 M² 个元素会显得你没有利用对称性，反而削弱创新性。

## 建议改成

```text
正规矩阵构造线程束负责 H 的上三角或下三角独立元素构造。对于 M 自由度机械臂，H 的独立元素数为 M(M+1)/2。6DOF 时为 21 个，7DOF 时为 28 个。其余对称元素通过镜像方式补全，或在寄存器求解器入口处按对称性读取。
```

这比“36 个元素全算”更稳，也更利于专利保护。
