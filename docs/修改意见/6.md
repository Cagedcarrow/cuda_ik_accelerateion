## 我的建议：先改成 10° 跑一遍

不要一上来改成 1° 或 2°。建议顺序是：

| 方案  |    姿态阈值 |          弧度值 | 建议           |
| --- | ------: | -----------: | ------------ |
| 当前  |     30° |     0.523599 | 已有数据         |
| 第一轮 | **10°** | **0.174533** | 最推荐先跑        |
| 第二轮 |      5° |     0.087266 | 若 10° 数据稳定再跑 |
| 第三轮 |      2° |     0.034907 | 仅作压力测试       |
| 第四轮 |      1° |     0.017453 | 很可能明显掉收敛率    |

**第一轮只把姿态阈值从 30° 改为 10°，位置阈值仍保持 0.03 m。**

原因是：你要先隔离变量。如果同时把 3 cm 改成 1 cm，又把 30° 改成 5°，数据变差后你无法判断到底是位置阈值还是姿态阈值导致的。

## 如果 10° 很好，是否继续改到 5°？

可以，但我建议：

> **10° 作为主论文默认阈值，5° 作为补充实验或附录。**

原因很简单：10° 已经足够解决“30° 太宽”的审稿风险；5° 可能会明显增加迭代次数，削弱主线速度优势。

除非 5° 下数据仍然很好，例如：

| 指标         | 5° 下仍满足       |
| ---------- | ------------- |
| ConvRate   | ≥ 0.98        |
| Throughput | 仍然明显高         |
| N=5000     | 不低于或接近 cuRobo |
| Avg Iters  | 没有暴涨          |

否则不要贸然把主阈值设成 5°。
