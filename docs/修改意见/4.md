四、引言修改要求

引言重写为以下结构：

1. 研究背景：机械臂 IK 是控制、抓取、标定、采样和轨迹生成中的基础计算原语；当目标位姿数量很大时，单次 IK 延迟不再是唯一指标，批量吞吐、收敛率和时间口径成为核心问题。
2. 研究问题：本文严格限定为标准 UR10 上的批量可达位姿 IK 查询，不包含碰撞检测、轨迹优化、路径规划和时间参数化。
3. 技术挑战：GPU 并不能自动解决 IK 加速问题，因为该类 kernel 存在 6×6 小矩阵、多轮迭代、强依赖链、分支收敛判定和小工作集访存等特征。
4. 本文方法：从 DLS 正规方程出发，将单次迭代归结为 6×6 SPD 小矩阵系统，并映射到 1 block/target、4 warp 协同、寄存器级 LDLT 的 CUDA 结构。
