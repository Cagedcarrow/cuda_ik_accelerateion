## 4.1 正运动学模型

定义 (n) 自由度串联机械臂关节变量：

[
\mathbf{q}
==========

[q_1,q_2,\ldots,q_n]^T
\in \mathbb{R}^{n}
]

末端位姿为：

[
\mathbf{T}(\mathbf{q})
======================

\begin{bmatrix}
\mathbf{R}(\mathbf{q}) & \mathbf{p}(\mathbf{q})\
\mathbf{0}^{T} & 1
\end{bmatrix}
\in SE(3)
]

对于 URDF 提取的关节原点变换和关节轴，可以写成：

[
\mathbf{T}(\mathbf{q})
======================

\prod_{i=1}^{n}
\left(
\mathbf{T}_{i}^{0}
\mathbf{R}(\mathbf{a}*i,q_i)
\right)
\mathbf{T}*{\mathrm{tip}}
]

其中：

* ( \mathbf{T}_{i}^{0} ) 是第 (i) 个关节的固定 origin transform；
* ( \mathbf{a}_i ) 是关节旋转轴；
* ( \mathbf{R}(\mathbf{a}_i,q_i) ) 是绕轴 ( \mathbf{a}_i ) 旋转 (q_i) 的 Rodrigues 旋转矩阵；
* ( \mathbf{T}_{\mathrm{tip}} ) 是末端 tool0 固定变换。

这个公式能把你前文“fixed transform 折叠”自然引出来。

---

## 4.2 位姿误差定义

目标位姿：

[
\mathbf{T}^{d}
==============

\begin{bmatrix}
\mathbf{R}^{d} & \mathbf{p}^{d}\
\mathbf{0}^{T} & 1
\end{bmatrix}
]

位置误差：

[
\mathbf{e}_{p}
==============

## \mathbf{p}^{d}

\mathbf{p}(\mathbf{q})
]

姿态误差建议用李代数形式：

[
\mathbf{e}_{R}
==============

\mathrm{Log}
\left(
\mathbf{R}^{d}\mathbf{R}(\mathbf{q})^{T}
\right)^{\vee}
]

总误差：

[
\mathbf{e}
==========

\begin{bmatrix}
\mathbf{e}*{p}\
\mathbf{e}*{R}
\end{bmatrix}
\in \mathbb{R}^{6}
]

收敛判据：

[
|\mathbf{e}_{p}|_2 < \varepsilon_p,
\quad
\theta_R < \varepsilon_R
]

其中：

[
\theta_R
========

\cos^{-1}
\left(
\frac{\mathrm{tr}(\mathbf{R}^{d}\mathbf{R}^{T})-1}{2}
\right)
]

你论文里有位置阈值 0.03 m、姿态阈值 0.5236 rad，这里就可以自然放进去。

## 4.3 DLS 迭代模型

数值 Jacobian：

[
\mathbf{J}_{:,j}
================

\frac{
\mathbf{e}(\mathbf{q}+\delta\mathbf{e}_j)
-----------------------------------------

\mathbf{e}(\mathbf{q})
}{\delta}
]

如果你实际用的是中心差分，就写：

[
\mathbf{J}_{:,j}
================

\frac{
\mathbf{e}(\mathbf{q}+\delta\mathbf{e}_j)
-----------------------------------------

\mathbf{e}(\mathbf{q}-\delta\mathbf{e}_j)
}{2\delta}
]

DLS 优化问题：

[
\Delta \mathbf{q}
=================

\arg\min_{\Delta \mathbf{q}}
\left|
\mathbf{W}
\left(
\mathbf{J}\Delta \mathbf{q}
---------------------------

\mathbf{e}
\right)
\right|_2^2
+
\lambda^2
|\Delta \mathbf{q}|_2^2
]

法方程：

[
\left(
\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{J}
+
\lambda^2\mathbf{I}
\right)
\Delta \mathbf{q}
=================

\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{e}
]

定义：

[
\mathbf{H}
==========

\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{J}
+
\lambda^2\mathbf{I}
]

[
\mathbf{g}
==========

\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{e}
]

所以：

[
\mathbf{H}\Delta \mathbf{q}=\mathbf{g}
]

关节更新：

[
\mathbf{q}^{k+1}
================

\Pi_{\mathcal{Q}}
\left(
\mathbf{q}^{k}+\alpha \Delta \mathbf{q}
\right)
]

其中 ( \Pi_{\mathcal{Q}} ) 表示关节限位投影。

## 4.4 LDLT 分解

因为：

[
\mathbf{H}
\in \mathbb{R}^{6\times 6}
]

并且在 (\lambda^2\mathbf{I}) 正则项作用下近似对称正定，所以可做：

[
\mathbf{H}
==========

\mathbf{L}\mathbf{D}\mathbf{L}^{T}
]

求解过程：

[
\mathbf{L}\mathbf{y}
====================

\mathbf{g}
]

[
\mathbf{D}\mathbf{z}
====================

\mathbf{y}
]

[
\mathbf{L}^{T}\Delta\mathbf{q}
==============================

\mathbf{z}
]

这就能解释为什么你使用 register LDLT，而不是通用求逆或 cuBLAS。

# 5. 第 4 章需要加入“矩阵存储设计”

你应该把 PaddedMat6x8 写成正式矩阵存储设计，而不是简单说“为了减少 bank conflict”。

例如：

对于 (6\times6) Jacobian：

[
\mathbf{J}
==========

[j_{r,c}],
\quad
r,c\in{0,\ldots,5}
]

在共享内存中不采用连续 (6\times6) 存储，而是扩展为：

[
\widetilde{\mathbf{J}}
\in
\mathbb{R}^{6\times 8}
]

其映射关系为：

[
\widetilde{J}_{r,c}
===================

J_{r,c},
\quad
0\le r<6,;0\le c<6
]

[
\widetilde{J}_{r,6}
===================

# \widetilde{J}_{r,7}

0
]

共享内存地址为：

[
\mathrm{addr}(r,c)
==================

r\cdot 8+c
]

这样就把“PaddedMat6x8”从工程名词变成了正式矩阵布局。

然后解释：

> 该布局以额外 (6\times2) 个元素的共享内存开销换取更规则的对齐访问，降低小矩阵构造阶段的 shared memory bank conflict。由于单 block 内共享矩阵规模很小，该 padding 对 occupancy 的影响可以忽略。

这就很像论文。

# 6. CUDA 并行结构要形式化

你应该增加一个“block/warp 映射公式”。

设 batch 中第 (b) 个目标为：

[
\mathbf{T}^{d}_{b},
\quad b=0,1,\ldots,N-1
]

CUDA grid 映射为：

[
b = \mathrm{blockIdx.x}
]

线程索引：

[
t=\mathrm{threadIdx.x},\quad 0\le t<128
]

warp 编号：

[
w=\left\lfloor \frac{t}{32}\right\rfloor
]

lane 编号：

[
l=t\bmod 32
]

于是：

| Warp  | 数学任务                                   | CUDA 任务            |
| ----- | -------------------------------------- | ------------------ |
| (w=0) | ( \mathbf{T}(\mathbf{q}), \mathbf{e} ) | FK 与误差计算           |
| (w=1) | ( \mathbf{J} )                         | 数值 Jacobian        |
| (w=2) | ( \mathbf{H},\mathbf{g} )              | Hessian / gradient |
| (w=3) | ( \Delta\mathbf{q} )                   | LDLT 与步长控制         |

这会让你的 CUDA 结构显得非常正规。

## 3 批量逆运动学问题建模

设标准串联机械臂具有 (n) 个主动关节，其关节变量为
[
\mathbf{q}=[q_1,q_2,\ldots,q_n]^T\in\mathbb{R}^{n}.
]
末端执行器相对于基坐标系的位姿可表示为
[
\mathbf{T}(\mathbf{q})=
\begin{bmatrix}
\mathbf{R}(\mathbf{q}) & \mathbf{p}(\mathbf{q})\
\mathbf{0}^{T} & 1
\end{bmatrix}
\in SE(3),
]
其中 (\mathbf{R}(\mathbf{q})\in SO(3)) 为末端姿态矩阵，(\mathbf{p}(\mathbf{q})\in\mathbb{R}^{3}) 为末端位置向量。对于由 URDF 提取的串联运动链，正运动学可写为
[
\mathbf{T}(\mathbf{q})=
\prod_{i=1}^{n}
\left(
\mathbf{T}*{i}^{0}
\mathbf{R}(\mathbf{a}*{i},q_i)
\right)
\mathbf{T}*{\mathrm{tip}},
]
其中 (\mathbf{T}*{i}^{0}) 表示第 (i) 个关节的固定原点变换，(\mathbf{a}*{i}) 表示该关节在局部坐标系下的旋转轴，(\mathbf{R}(\mathbf{a}*{i},q_i)) 表示绕 (\mathbf{a}*{i}) 旋转 (q_i) 的旋转矩阵，(\mathbf{T}*{\mathrm{tip}}) 表示末端 tool0 的固定变换。

给定目标位姿
[
\mathbf{T}^{d}=
\begin{bmatrix}
\mathbf{R}^{d} & \mathbf{p}^{d}\
\mathbf{0}^{T} & 1
\end{bmatrix},
]
位置误差定义为
[
\mathbf{e}*{p}=\mathbf{p}^{d}-\mathbf{p}(\mathbf{q}),
]
姿态误差采用旋转群上的对数映射表示为
[
\mathbf{e}*{R}=
\mathrm{Log}
\left(
\mathbf{R}^{d}\mathbf{R}(\mathbf{q})^{T}
\right)^{\vee}.
]
因此，单个 IK 查询的六维误差向量为
[
\mathbf{e}(\mathbf{q})=
\begin{bmatrix}
\mathbf{e}*{p}\
\mathbf{e}*{R}
\end{bmatrix}
\in\mathbb{R}^{6}.
]

本文采用阻尼最小二乘方法求解关节增量。第 (k) 次迭代中，关节增量 (\Delta\mathbf{q}) 由如下加权最小二乘问题确定：
[
\Delta \mathbf{q}
=================

\arg\min_{\Delta \mathbf{q}}
\left|
\mathbf{W}
\left(
\mathbf{J}\Delta\mathbf{q}-\mathbf{e}
\right)
\right|_2^2
+
\lambda^2
|\Delta\mathbf{q}|_2^2,
]
其中 (\mathbf{J}\in\mathbb{R}^{6\times n}) 为位姿误差对关节变量的 Jacobian，(\mathbf{W}) 为位置与姿态误差权重矩阵，(\lambda) 为阻尼系数。上述优化问题对应的法方程为
[
\left(
\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{J}
+
\lambda^2\mathbf{I}
\right)
\Delta\mathbf{q}
================

\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{e}.
]
令
[
\mathbf{H}=
\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{J}
+
\lambda^2\mathbf{I},
\quad
\mathbf{g}=
\mathbf{J}^{T}\mathbf{W}^{T}\mathbf{W}\mathbf{e},
]
则每次 DLS 迭代可归结为固定规模线性系统
[
\mathbf{H}\Delta\mathbf{q}=\mathbf{g}.
]
对于 UR10 六自由度机械臂，有 (\mathbf{J}\in\mathbb{R}^{6\times6})、(\mathbf{H}\in\mathbb{R}^{6\times6})。该小矩阵系统规模固定、结构简单，适合在单个 CUDA block 内采用寄存器级 LDLT 分解求解，而不适合调用面向大矩阵的通用线性代数库。
