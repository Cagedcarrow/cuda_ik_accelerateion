# 一、最高优先级修改：修正 Warp 2 的线程映射错误

## 1. 当前问题

当前论文中仍然存在如下错误表述：

> W2 / Warp 2：Lane 64–95，负责阻尼正规矩阵 H 的 36 个元素，每元素 1 lane。

这是错误的。

原因：

```text
Lane 64–95 一共只有 32 个线程；

32 个线程不可能“一线程一元素”覆盖 36 个元素。
```

因此必须修改所有类似表述。

---

## 2. 统一修改方案

请将 Warp 2 的职责统一修改为：

> Warp 2 只计算阻尼正规矩阵 H 的上三角独立元素。

因为 H 是对称矩阵：

```math
H_{ij}=H_{ji}
```

所以 6DOF 情况下只需要计算：

```math
6(6+1)/2 = 21
```

个上三角元素。

这 21 个元素完全可以由 Warp 2 的 21 个 lane 完成。

# 二、修正 DLS / Jacobian 的残余矛盾

## 1. 当前目标

全文必须统一采用如下符号体系：

```math
x(q) = [p(q); r(q)]
```

表示末端位姿向量。

```math
e(q) = x^d - x(q)
```

表示目标位姿与当前位姿之间的误差。

```math
J = \frac{\partial x}{\partial q}
```

表示末端位姿对关节角的 Jacobian，而不是误差对关节角的 Jacobian。

因此：

```math
x(q+\Delta q) \approx x(q) + J\Delta q
```

```math
e(q+\Delta q) = x^d - x(q+\Delta q) \approx e(q) - J\Delta q
```

DLS 问题为：

```math
\Delta q = \arg\min_{\Delta q} \|W(e - J\Delta q)\|_2^2 + \lambda^2 \|\Delta q\|_2^2
```

正规方程为：

```math
(J^T W^2 J + \lambda^2 I)\Delta q = J^T W^2 e
```

---

## 2. 必须删除的错误表述

请全文搜索：

```text
J 为位姿误差对关节角的雅可比矩阵
```

替换为：

```text
J 为末端执行器位姿 x(q) 对关节角 q 的雅可比矩阵，即 J = ∂x/∂q。
```

请全文搜索：

```math
e(q+\Delta q) \approx e(q) + J\Delta q
```

如果存在，必须删除或改为：

```math
e(q+\Delta q) \approx e(q) - J\Delta q
```

请全文搜索：

```text
J = ∂e/∂q
```

替换为：

```text
J = ∂x/∂q
```

---

## 3. 修正数值 Jacobian 公式

请全文统一为：

```math
J_{:,j}(q)=\frac{x(q+\varepsilon e_j)-x(q-\varepsilon e_j)}{2\varepsilon}
```

不要再写成：

```math
J_{:,j}(q)=\frac{e(q+\varepsilon e_j)-e(q-\varepsilon e_j)}{2\varepsilon}
```

因为当前体系下 J 是 `∂x/∂q`，不是 `∂e/∂q`。
