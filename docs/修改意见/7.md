## 结论

**10° 仍然偏大。**
它比 30° 好很多，但如果你想让论文更抗质疑，建议不要只跑 10°，而是做一组姿态阈值扫描。

你现在论文里姿态收敛阈值是：

[
\theta_R < \varepsilon_R
]

当前取 (\varepsilon_R=0.5236\ \text{rad})，即 30°。

严格说，**工业机器人没有一个统一的“正常工业标准角度”**。ISO 9283 是工业机器人性能测试标准，关注 pose accuracy、pose repeatability 等测试方法，而不是规定所有任务都必须用某个固定姿态误差角。([ISO][1])
例如 UR10e 官方规格给的是 **pose repeatability ±0.05 mm per ISO 9283**，这是重复定位精度，不等价于你的 IK 姿态收敛阈值。([优傲机器人][2])

# 一、姿态阈值大致怎么分

可以按工程任务这样理解：

|    姿态阈值 | 工程含义                 | 适合写法                |
| ------: | -------------------- | ------------------- |
|     30° | 很宽，只适合粗候选筛选          | 不建议作为主实验默认值         |
|     10° | 仍偏宽，但可用于中低精度批量候选生成   | 可以作为 Loose / Medium |
|      5° | 比较稳妥，适合普通批量 IK 论文主阈值 | **推荐优先测试**          |
|      2° | 较严格，对单 seed DLS 有压力  | 可作为 Strict          |
|      1° | 高精度姿态要求，可能明显掉收敛率     | 可作为 Very Strict     |
| 0.5° 以下 | 精密装配/视觉伺服级别          | 不建议作为主线，除非数据很好      |

高精度装配论文中，毫米级位置误差和 1° 以内姿态误差是常见目标。例如一个工业装配任务报告了平均 2.16 mm 和 0.64° 的位姿估计误差；另一个视觉伺服工作报告可达到 0.6 mm 和 0.4° 的相对位姿精度。([arXiv][3])
但这些是**精密装配/视觉伺服任务**，不是所有工业机器人 IK benchmark 的统一标准。

# 三、哪个数值最适合替换论文主阈值？

我的判断：

## 最优先争取：5°

如果 5° 下满足：

| 指标            | 要求             |
| ------------- | -------------- |
| ConvRate      | ≥ 0.98         |
| Throughput    | 不低于原来的 60%–70% |
| Avg Iters     | 不暴涨到接近最大迭代次数   |
| N=1000 / 5000 | 数据还能稳定         |

那你就可以把论文默认姿态阈值从 30° 直接改成：

[
\varepsilon_R = 0.0873\ \text{rad} \approx 5^\circ
]

这会非常明显地降低审稿风险。

---

## 次优选择：10°

如果 5° 数据掉得比较严重，而 10° 很稳，那就用 10° 作为主阈值，同时补一张 5° / 2° 的敏感性表。

写法：

> 本文默认采用 10° 姿态阈值作为标准批量 IK 查询口径，并进一步通过 5° 和 2° 阈值验证误差收紧后的性能边界。

这样也可以接受。

---

## 不建议直接用：1°

1° 对你的当前单 seed DLS 可能太严。它更适合作为压力测试，不适合一上来替换主实验。

如果 1° 下收敛率明显下降，并不说明你的论文失败，只说明：

> 单 seed DLS 在严格姿态约束下需要多 seed 或二阶段 refinement。

这可以写进局限性。
