# Amdahl 定律与端到端性能瓶颈分析

> 修正日期: 2026-06-05 | 基于论文 v3 修正后的端到端耗时分解

## Amdahl 定律

Amdahl 定律描述并行化的理论加速上限：

```
S_max = 1 / ((1 - f_parallel) + f_parallel / N)

当 N → ∞ 时: S_max = 1 / (1 - f_parallel) = 1 / f_serial
```

## v2.0 CPU 端到端耗时分解

| 阶段 | 耗时 (s) | 占比 | 可并行化? |
|------|---------|------|----------|

## 正确 Amdahl 分析（论文 v3 修正后）

### 端到端加速比理论上限

```
固有串行部分: f_serial = (1.5 + 1.0) / 10.0 = 0.25 (轨迹生成 + 回放插值)
S_max = 1 / 0.25 = 4.0×

即: 即使 IK 和碰撞检测实现无限加速，端到端加速比不可能超过 4.0×
```

### 实际端到端加速比

```
v3.0 端到端:
  轨迹生成: 1.5 s (CPU, 不变)
  回放插值: 1.0 s (CPU, 不变)
  碰撞检测: 0.7 s (GPU OBB+GJK + CPU FCL 回退)
  GPU IK:   0.0064 s (960× 加速)
  总计:     ~3.2 s

端到端加速比: 10.0 / 3.2 ≈ 3.1×
```

### 差距分析

| 项目 | 值 | 说明 |
|------|-----|------|
| Amdahl 理论上限 | **4.0×** | IK + 碰撞无限加速 |
| 实际端到端 | **3.1×** | 碰撞仍含 CPU FCL 回退 (0.7s) |
| 差距 | 0.9× | 完全 GPU 化碰撞可缩小至 ~3.8× |
| 进一步上限 | — | GPU 化轨迹生成+回放后，上限本身会上移 |

### ⚠️ 此前错误分析（已修正）

论文此前将 Amdahl 理论上限计算为 **52.6×**，该错误源于：
- 仅考虑 IK (f=0.91) 和碰撞 (f=0.09) 两项的可并行比例
- **忽略了轨迹生成 (1.5s) 和回放插值 (1.0s) 这两个更大的串行瓶颈**
- 错误地将串行部分视为接近零 → S_max ≈ 1/0.019 ≈ 52.6×

修正后的正确理论上限为 **4.0×**，与实际 3.1× 一致。

## IK 求解 Amdahl 分析（算法内部）

仅考虑 IK 求解本身（不含轨迹生成等）：

```
f_parallel_IK = 0.98 (273 个独立目标完全并行)
S_IK_max = 1 / (1 - 0.98) = 50×

但 GPU 不仅提供了并行度，还提供了:
  - 常量内存广播 (32× 带宽放大)
  - 共享内存 Bank 冲突消除
  - 寄存器零溢出执行
  - 单次 launch 消除 192 次循环

实测加速比 960× >> Amdahl 预测 50×
→ 说明 GPU 微架构优化的贡献远超单纯并行度增加
```

## 端到端瓶颈消除路径

| 优化 | 当前耗时 | 目标耗时 | 预期收益 |
|------|---------|---------|---------|
| 碰撞完全 GPU 化 | 0.7 s | ~0.001 s | 端到端 3.2s → 2.5s (3.2× → 4.0×) |
