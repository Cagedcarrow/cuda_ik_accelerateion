## 四、阈值收紧影响分析

### CUDA B5 从 Loose → Strict 的变化

| N | TP 变化 | ConvRate 变化 | Iters 变化 |
|---|:---:|:---:|:---:|
| 100 | +5.0% | 1.000→1.000 | +6.5% |
| 500 | +4.8% | 0.996→0.998 | +6.5% |
| 1000 | -5.6% | 0.998→0.998 | +6.1% |
| 5000 | -6.3% | 0.9994→0.9998 | +6.4% |

**结论：阈值从 Loose 收紧到 Strict，CUDA B5 吞吐波动在 ±6% 以内，收敛率反而略微提升。**

### cuRobo 从 Loose → Strict 的变化

| N | TP 变化 |
|---|:---:|
| 100 | -2.5% |
| 500 | +6.9% |
| 1000 | +2.3% |
| 5000 | -1.1% |

**结论：cuRobo 在三档阈值下吞吐几乎不变，对阈值不敏感。**

## 五、按 8.md 判定规则

### 情况 A 判定：Strict 能否升级为主线？

| 判定条件 | 门槛 | 实际 | 结果 |
|---------|------|------|:---:|
| CUDA ConvRate | ≥ 0.98 | 最低 0.998 (N=500/1000) | ✓ |
| CUDA TP | ≥ Medium 的 70% | N=5000: 164k vs 169k = 97.2% | ✓ |
| N=5000 speedup | ≥ 0.9× | 1.05× | ✓ |
| Avg Iters | 不接近 max_iter=160 | 最高 16.27 | ✓ |

### 🏆 结论：Strict (5mm/1°) 满足所有升级条件！

但按 8.md 保守策略，建议：
- **主 benchmark 用 Medium (10mm/5°)**，审稿风险最低
- **Strict (5mm/1°) 作为"严格阈值下性能边界"**，证明方法在极端条件下的鲁棒性
- 如果导师/合作者同意，可以直接将 Strict 升级为主线——这会让论文显著更强

> 本文采用位置误差与姿态误差独立阈值进行收敛判定。为评估不同任务精度要求下的性能边界，实验设置 Loose、Medium 和 Strict 三档阈值，分别对应 (30mm/10°)、(10mm/5°) 和 (5mm/1°)。其中 Medium 作为主 benchmark 默认口径。
